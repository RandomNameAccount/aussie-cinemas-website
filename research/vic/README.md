# Victorian archive expansion: research data (staging only)

Raw source extracts and the consolidated Victorian database. Not used by the website until the build scripts read the consolidated files. Do not deploy without Tony's approval.

## Licences of the files in this folder
- `caarp-part*.json` and the CAARP-derived fields in `vic-master.*`: from the CAARP database (Deb Verhoeven with others, eds, Cinema and Audiences Research Project), **CC BY-NC-SA 3.0**. Shared here under the same licence, non-commercially.
- `geonames-vic.json`: GeoNames postal codes, CC BY 4.0.
- `cinematreasures*.json`, `vhd.json`: facts (names, places, status, listing numbers) only, kept for reconciliation and citation.
